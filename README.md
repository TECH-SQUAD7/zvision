# Z—Vison

An interactive smart-glasses concept built with TanStack Start, React, TypeScript, Vite, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run lint
npm run test
npm run build
```

Deploy to Vercel as a standard TanStack Start application. Configure the optional `VITE_JOURNEY_URL` environment variable in the Vercel project settings when needed.
